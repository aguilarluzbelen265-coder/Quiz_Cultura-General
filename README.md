# Quiz_Cultura-General
QUIZ CULTURA GENERAL
DESCRIPCION:Quiz de preguntas y respuespuestas de opcion multiple desarrollada en python utlilizando la libreria "Tkinter"
El sistema carga las preguntas desde un archivo externo en formato JSON,lleva el control del puntaje,cuenta con un sistema de vidas inicialies,temporizador.
